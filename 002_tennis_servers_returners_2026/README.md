# ATP Best Servers and Returners — 2026

A mini data curiosity exploring who the best servers and returners are on the ATP Tour in 2026.

## Question

Who are the top 5 servers and top 5 returners on the ATP Tour in 2026?

## Data Source

Jeff Sackmann ATP Tennis Dataset

## Tools

- Python
- Pandas
- Jupyter Notebook
- Tableau

## Analysis

Serve and return performance will be calculated using ATP match statistics such as:

- Aces
- Double faults
- First serve percentage
- First serve points won
- Second serve points won
- Break points saved
- Return points won
- Break point opportunities

## Visualization

The final visualization will be created in Tableau.
